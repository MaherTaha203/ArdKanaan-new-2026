# مواصفة توكنات التصميم — ArdKanaan-new-2026

**الحالة:** مقترح للاعتماد. هذه الوثيقة هي **مصدر الحقيقة الوحيد** لقيم التصميم (ألوان، خطوط، مسافات، حواف، ظلال، تركيز، حركة). لا تُكرَّر هذه القيم داخل المكوّنات، بل تُشتق منها. لا تمنح الوثيقة إذنًا بكتابة كود أو تثبيت حزم.

أسماء المتغيرات متوافقة مع اصطلاح shadcn/ui على Tailwind v4 (متغيرات CSS على `:root` و`.dark`)، لتسهيل التنفيذ المباشر لاحقًا.

## 1. المبادئ

- **RTL أولًا:** الاتجاه الافتراضي `rtl`؛ تُستخدم الخصائص المنطقية (inline-start/end) لا left/right.
- **الأرقام إنجليزية** `0123456789` دائمًا، وصيغة التاريخ `YYYY-MM-DD`.
- **الوصولية (WCAG 2.1 AA):** نص عادي تباين ≥ 4.5:1، نص كبير/أيقونات ≥ 3:1. لا يُشرح المعنى باللون وحده (أيقونة + نص دائمًا).
- **وضعان:** فاتح (أساسي) وداكن، بنفس التوكنات الدلالية وقيم مختلفة.
- **دلالة لا مظهر:** المكوّن يستهلك `--primary` لا «الأزرق»؛ تغيير العلامة لاحقًا يتم من مكان واحد.

## 6. الخطوط (Typography)

- **العائلة:** `IBM Plex Sans Arabic`، احتياطي النظام: `system-ui, "Segoe UI", sans-serif`.
- **الأرقام:** تُعرض بأرقام لاتينية (`font-feature-settings` دون تحويل عربي-هندي)، وتُحاذى جدوليًا في الجداول (`tabular-nums`).

| التوكن | الحجم / الارتفاع | الاستخدام |
|---|---|---|
| `--text-xs` | 12px / 16px | تلميحات، تسميات ثانوية |
| `--text-sm` | 14px / 20px | نص الجداول والحقول |
| `--text-base` | 16px / 24px | النص الأساسي |
| `--text-lg` | 18px / 28px | عناوين فرعية |
| `--text-xl` | 20px / 28px | عناوين الأقسام |
| `--text-2xl` | 24px / 32px | عنوان الصفحة |
| `--text-3xl` | 30px / 36px | أرقام لوحة المعلومات |

أوزان: `--font-normal: 400`, `--font-medium: 500`, `--font-semibold: 600`, `--font-bold: 700`.

## 9. الحركة (Motion)

- `--duration-fast: 120ms` · `--duration-base: 200ms` · `--duration-slow: 320ms`.
- `--ease-standard: cubic-bezier(0.2, 0, 0, 1)`.
- احترام `prefers-reduced-motion`: تُعطَّل الانتقالات غير الضرورية.

## 10. نقاط الاستجابة و z-index

- نقاط: `sm: 640px` · `md: 768px` · `lg: 1024px` · `xl: 1280px`.
- طبقات: `--z-base: 0` · `--z-dropdown: 1000` · `--z-sticky: 1100` · `--z-overlay: 1200` · `--z-modal: 1300` · `--z-toast: 1400`.

## 11. إرشادات مكوّنات أساسية

- **الجداول:** رأس لاصق، صفوف بتباين خفيف عند التحويم، أعمدة أرقام بـ `tabular-nums` ومحاذاة مناسبة للـ RTL؛ على الشاشات < `md` تتحول الصفوف إلى بطاقات بدل تصغير الجدول.
- **النماذج:** تسمية فوق الحقل، رسالة خطأ أسفله بلون `--destructive` + أيقونة + نص يشرح السبب والخطوة التالية؛ حفظ المدخلات عند الخطأ؛ زر الإرسال يُعطَّل أثناء التنفيذ لمنع النقر المكرر.
- **التأكيدات الحساسة:** حوار بلون `--destructive` للإجراءات الهدّامة (إلغاء تسجيل، استبدال كامل) مع نص صريح وزر تأكيد منفصل.
- **رسائل النجاح:** toast عبر `sonner` يُطلق **بعد** نجاح العملية فعليًا فقط.
- **الحالات الأربع:** تحميل (هيكل عظمي skeleton)، فراغ (أيقونة + نص + إجراء مقترح)، خطأ (سبب + إعادة محاولة)، نجاح.

## 12. حدود هذه الوثيقة

- القيم مقترحة وتخضع لفحص تباين آلي ومراجعة بصرية قبل الاعتماد النهائي.
- لا كود ولا حزم في هذه المرحلة؛ المواصفة مرجع للتنفيذ لاحقًا.
- عند التنفيذ تُسقط هذه التوكنات في ملف واحد (`globals.css` / `tokens.css`) كمتغيرات CSS، وتُشتق منها إعدادات Tailwind.

## 13. الخطوات التالية

1. اعتماد لوحة القيم (أو تعديلها) + تأكيد الخط الأساسي بعد مقارنة بصرية.
2. بناء نموذج أولي للوحة الرئيسية وقائمة الطلاب باستخدام هذه التوكنات فقط.
3. فحص التباين ووضوح الأرقام وتجاوب الجداول في RTL.
